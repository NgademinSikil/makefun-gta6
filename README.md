Solmar Heat is an original open-world crime game in the spirit of GTA 6, set in the fictional coastal city of Solmar. Explore a 9×9-block city on foot and by car, with traffic and pedestrians, cars to steal and drive, a wanted level with police cruisers that chase, ram and bust you, missions and a story, combat, and a HUD with a minimap, health, armor, money and the clock. Start a new game or keep playing from a save. Built with three.js as static files — no build step, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```
